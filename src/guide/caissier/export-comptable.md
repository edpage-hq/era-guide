# Export comptable

Depuis la page **Facturation**, trois boutons vous permettent de
télécharger les données financières de l'établissement sous une forme
exploitable par votre comptable ou pour vos propres archives. Chaque
bouton télécharge le fichier immédiatement, sans réglage préalable.

| Bouton                  | Contenu du fichier                                                                                                                                                                 | Usage typique                                                                                                 |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **Exporter en CSV**     | Un tableau brut de tous les paiements encaissés : élève, article de frais, montant, méthode, référence, date, et qui l'a enregistré.                                               | Vérifier ou trier les paiements dans un tableur.                                                              |
| **Exporter SYSCOHADA**  | Un journal de caisse combiné : les encaissements (paiements reçus) et les décaissements (dépenses approuvées), classés par date avec un compte débit/crédit pour chaque mouvement. | Alimenter la comptabilité de l'établissement selon le plan comptable SYSCOHADA.                               |
| **Exporter par classe** | Un relevé détaillé, classe par classe puis élève par élève : chaque article de frais avec le montant dû, le montant payé, le reste à payer et le pourcentage réglé.                | Faire un point de situation avec un enseignant ou un directeur de site sur l'état des paiements d'une classe. |

## Exporter en CSV

Cliquez sur **Exporter en CSV** pour télécharger un fichier listant
chaque paiement enregistré individuellement. Ce fichier est utile pour
retrouver rapidement un paiement précis ou pour l'importer dans un autre
outil.

## Exporter au format SYSCOHADA

Cliquez sur **Exporter SYSCOHADA** pour télécharger un journal de caisse
qui rapproche les paiements reçus (encaissements) et les dépenses déjà
**approuvées** (décaissements) — voir [Dépenses](/guide/caissier/depenses).
Chaque ligne indique la date, le journal concerné, les comptes de débit
et de crédit, un libellé et un montant, dans un format directement
utilisable par un cabinet comptable travaillant avec le plan comptable
SYSCOHADA.

::: info
Seules les dépenses déjà approuvées par un administrateur apparaissent
dans cet export ; une dépense encore en attente n'y figure pas.
:::

## Exporter par classe

Cliquez sur **Exporter par classe** pour télécharger un relevé qui
détaille, pour chaque élève de chaque classe, l'état de chaque article
de frais (montant dû, montant payé, reste à payer, pourcentage réglé)
ainsi que la liste de ses paiements. C'est le format le plus adapté pour
un suivi classe par classe.
