# Présences et absences

Cette page couvre l'appel quotidien des classes et le traitement des
justificatifs d'absence ou de retard soumis par les familles depuis leur
espace parent.

## Faire l'appel quotidien

1. Ouvrez **Vie scolaire → Présences**. La liste affiche toutes vos
   classes, avec un badge **Appel du jour** indiquant combien d'élèves ont
   déjà été pointés sur le total inscrit (par exemple « 18/24 fait »).
2. Cliquez sur **Faire l'appel** sur la ligne de la classe concernée.
3. Par défaut, la page affiche le jour en cours ; changez la date en haut
   de page si vous devez compléter ou corriger l'appel d'un autre jour.
4. Pour chaque élève, réglez le **Statut** : **Présent**, **Absent** ou
   **Retard**.
   - Si vous choisissez **Retard**, indiquez le nombre de **Minutes de
     retard**.
   - Cochez **Justifié** si l'absence ou le retard est déjà couvert par un
     motif connu, et ajoutez une **Note** libre si besoin (par exemple
     « certificat médical fourni »).
5. Cliquez sur **Enregistrer** — tout l'appel de la classe est enregistré
   en une fois.

## Traiter les justificatifs d'absence

Les familles soumettent leurs justificatifs d'absence ou de retard depuis
leur espace parent ; ils apparaissent dans **Vie scolaire → Justifications
d'absence** avec le statut **En attente**.

1. Ouvrez **Justifications d'absence**. La liste affiche, pour chaque
   demande, l'élève, sa classe, la date concernée, le motif indiqué et son
   statut. Cliquez sur une ligne pour ouvrir le détail.
2. Si un document a été joint, téléchargez-le via **Télécharger le
   document** pour le vérifier avant de statuer.
3. Sur une demande **en attente**, choisissez :
   - **Approuver** — la justification est validée immédiatement, sans
     saisie supplémentaire ;
   - **Rejeter** — une boîte de dialogue vous demande de saisir un
     **Motif du rejet**, obligatoire, avant de confirmer.

Une fois traitée, la demande passe au statut **Approuvée** ou **Rejetée** ;
un justificatif rejeté affiche son motif de rejet directement dans la
liste.
