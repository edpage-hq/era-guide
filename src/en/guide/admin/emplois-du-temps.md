# Timetables

This page covers building a class's weekly timetable. It assumes the
class already exists and that at least one teacher is assigned to it (see
[Staff and user accounts](/en/guide/admin/personnel-utilisateurs)) —
without a teacher assignment, you can't add any slot.

## Build a class's timetable

From **School Structure → Classes**, click **Timetable** on the row for
the class you want.

To add a slot:

1. Click **Add slot**.
2. Fill in the fields below.
3. Repeat for each slot of the week. The trash-can button on a row
   removes that slot from the form.
4. Click **Save**.

| Field             | Detail                                                                                                                          |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Day               | Monday through Sunday                                                                                                           |
| Start time        | —                                                                                                                               |
| End time          | —                                                                                                                               |
| Teacher / subject | list of existing teacher assignments for this class; an assignment with no subject (qualitative class) is shown as "Generalist" |

If no teacher is assigned to the class yet, a message tells you so and the
**Add slot** button stays disabled — go create the necessary teacher
assignments first.

## Export the timetable

The **Export to calendar** button (top of the page) downloads the class's
timetable in a calendar format that can be imported into a calendar app.
