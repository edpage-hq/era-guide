# Era Admission

Era Admission est le canal par lequel une école découvre et adopte ERA
avant, éventuellement, de gérer son propre serveur. Ce n'est pas le
quotidien d'un établissement déjà équipé — pour ça, voir le
[guide par rôle](/guide/).

Deux publics bien distincts se croisent ici :

- **[Les écoles](/admission/ecoles/inscription-et-demo)** — une école qui
  découvre ERA s'inscrit gratuitement en ligne, peut activer une
  démonstration complète pendant une durée limitée, puis passer à une
  licence payante (à la carte, par pôle) accompagnée par l'équipe edPage.
- **[L'équipe edPage](/admission/staff-edpage/)** — le personnel commercial/support
  edPage dispose d'un panneau interne séparé pour gérer les établissements
  inscrits : accorder une licence, clore une démonstration, purger un
  compte expiré.

Ces deux parcours n'ont rien à voir avec les comptes utilisateurs d'un
établissement (rôles admin, enseignant, etc.) : ils se déroulent sur le
domaine central d'ERA, avant même qu'un compte d'établissement existe.
