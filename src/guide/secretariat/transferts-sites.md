# Transferts de site

Un parent peut demander, depuis son espace, à transférer son enfant d'un
site de l'établissement vers un autre (par exemple d'un campus à un
autre). La page **Mobilité inter-site** liste ces demandes et vous permet
de les faire aboutir. Une demande doit être approuvée à la fois par le
site d'origine et par le site de destination avant que le transfert ne
soit effectif — vous jouez ce rôle des deux côtés, sauf pour un site qui a
une **direction de site** : c'est alors elle qui valide la part de ce site
(voir [Direction](/guide/direction/)). Son bloc affiche **En attente de la
validation de ce site**, et vous ne pouvez refuser la demande que si l'un
des deux sites relève de vous.

::: info
Cette page concerne uniquement les transferts d'**élèves** entre deux
sites. Les transferts de personnel entre sites sont une fonctionnalité
distincte, réservée à l'administration.
:::

## Consulter la file d'attente

La page affiche pour chaque demande l'élève concerné, le site d'origine,
le site de destination et le statut (**En attente**, **Approuvé** ou
**Refusé**). Utilisez le filtre de statut pour ne voir que les demandes
qui vous intéressent, puis cliquez sur **Examiner** pour ouvrir une
demande.

## Examiner une demande

La page de détail affiche qui a **demandé** le transfert, le **site
d'origine**, le **site de destination**, le **département** souhaité sur
le nouveau site et, si elle a été renseignée, le **motif** de la demande.

## Approuver un transfert

Le formulaire présente deux blocs distincts, l'un pour chaque site
concerné :

1. Dans **Validation du site d'origine**, cliquez sur **Approuver
   l'origine**. Si ce bloc affiche déjà le nom d'une personne, ce site a
   déjà donné son accord et vous n'avez rien à faire ici.
2. Dans **Validation du site de destination**, choisissez la **classe**
   d'accueil sur le nouveau site (l'occupation de chaque classe est
   indiquée, par exemple `18/25`). Si la classe a atteint sa capacité,
   cochez **Forcer l'affectation même si la classe a atteint sa
   capacité** pour l'assigner malgré tout, saisissez le **Motif du
   dépassement**, puis cliquez sur **Approuver la destination**.

Dès que les deux sites ont donné leur accord — peu importe l'ordre — le
transfert est exécuté automatiquement : l'élève est déplacé vers le
nouveau site, département et classe, sans action supplémentaire de votre
part.

::: tip
La notification d'une nouvelle demande (par exemple sur votre téléphone)
ouvre la page [À approuver](/guide/direction/a-approuver) : elle permet de
valider le départ ou l'arrivée de votre site, ou de refuser la demande, sans
naviguer dans le reste de l'appli.
:::

::: info Dépassements de capacité
Le motif est obligatoire quand la classe est pleine. Le dépassement est
enregistré (qui, quand, effectif, motif) et la direction du site, la
direction générale et les administrateurs en sont informés.
:::

## Refuser une demande

1. Depuis la page de détail d'une demande en attente, cliquez sur
   **Refuser**.
2. Indiquez le **Motif de refus** (obligatoire).
3. Confirmez en cliquant à nouveau sur **Refuser**.

Une demande refusée ne peut plus être approuvée : la famille doit en
soumettre une nouvelle si elle souhaite réessayer.
