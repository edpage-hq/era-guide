# Internat

En tant que responsable de l'internat, vous avez deux missions dans ERA :
gérer les lits (les créer, les modifier, et affecter un élève interne à
chacun) et enregistrer chaque jour les présences en internat, le soir et le
matin. Le menu de gauche vous donne accès à deux pages, dans le groupe
« Services aux élèves » : **Lits de l'internat** et **Présences internat**.

## Gérer les lits

La page **Lits de l'internat** liste tous les lits de l'internat, avec le
site, la chambre, le lit et l'élève qui l'occupe (ou « Non affecté » s'il
est libre). Vous pouvez filtrer la liste par site avec le menu déroulant
en haut de la page, ou rechercher un lit par code de chambre ou de lit.
Cliquez sur une ligne pour ouvrir un panneau récapitulatif avec le site et
l'occupant.

### Créer un lit

1. Cliquez sur **Nouveau lit** en haut de la page **Lits de l'internat**.
2. Choisissez le **Site** auquel appartient ce lit.
3. Renseignez la **Chambre** (le code de la chambre) et le **Lit** (le code
   du lit dans cette chambre).
4. Si un élève interne doit occuper ce lit dès sa création, sélectionnez-le
   dans le champ **Occupant**. Vous pouvez laisser ce champ vide et
   affecter un élève plus tard.
5. Cliquez sur **Enregistrer**.

Seuls les élèves qui n'ont pas encore de lit apparaissent dans la liste
**Occupant** (en plus, sur la page de modification, de l'élève déjà
affecté à ce lit).

### Modifier un lit ou réaffecter son occupant

1. Depuis la page **Lits de l'internat**, cliquez sur **Modifier** sur la
   ligne du lit concerné.
2. Mettez à jour le site, la chambre, le lit ou l'occupant selon les
   besoins. Pour libérer un lit, choisissez à nouveau **Non affecté** dans
   le champ **Occupant** ; pour affecter un autre élève, sélectionnez-le
   dans la liste.
3. Cliquez sur **Enregistrer les modifications**.

### Supprimer un lit

Depuis la page **Lits de l'internat**, cliquez sur **Supprimer** sur la ligne
du lit concerné, puis confirmez dans la fenêtre qui s'affiche. Un lit
occupé ne peut pas être supprimé : libérez d'abord son occupant (en
modifiant le lit et en repassant l'**Occupant** sur « Non affecté »)
avant de le supprimer.

## Enregistrer les présences en internat

La page **Présences internat** vous permet de saisir, pour chaque élève
ayant un lit affecté, s'il est présent ou absent — le soir ou le matin.
Seuls les élèves ayant déjà un lit affecté (voir « Gérer les lits »
ci-dessus) apparaissent dans cette liste ; si la liste est vide, c'est
qu'aucun lit n'est encore affecté.

1. Ouvrez la page **Présences internat**.
2. Choisissez la **date** concernée avec le sélecteur de date en haut de
   la page.
3. Choisissez le **moment** : **Soir** ou **Matin**. Changer la date ou le
   moment recharge automatiquement la liste avec les présences déjà
   saisies pour ce choix, s'il y en a.
4. Pour chaque élève de la liste (avec son site, sa chambre et son lit),
   choisissez son statut dans le menu déroulant correspondant : **Présent**
   ou **Absent**.
5. Une fois toutes les lignes vérifiées, cliquez sur **Enregistrer**.

Vous pouvez revenir sur une date déjà saisie à tout moment pour corriger
un statut : les valeurs déjà enregistrées pour cette date et ce moment
sont pré-remplies.
