# Accounting export

From the **Billing** page, three buttons let you download the school's
financial data in a form your accountant can use, or for your own
records. Each button downloads the file immediately, with no setup
required.

| Button               | File contents                                                                                                                                      | Typical use                                                            |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **Export as CSV**    | A raw table of every payment collected: student, fee item, amount, method, reference, date, and who recorded it.                                   | Checking or sorting payments in a spreadsheet.                         |
| **Export SYSCOHADA** | A combined cash journal: payments received and approved expenses, sorted by date with a debit/credit account for each movement.                    | Feeding the school's accounting under the SYSCOHADA chart of accounts. |
| **Export by class**  | A detailed statement, class by class then student by student: each fee item with the amount due, amount paid, remaining balance, and percent paid. | Reviewing a class's payment status with a teacher or site director.    |

## Export as CSV

Click **Export as CSV** to download a file listing every recorded
payment individually. This file is useful for quickly finding a
specific payment or importing it into another tool.

## Export in SYSCOHADA format

Click **Export SYSCOHADA** to download a cash journal that reconciles
payments received (cash inflows) with expenses that have already been
**approved** (cash outflows) — see [Expenses](/en/guide/caissier/depenses).
Each row shows the date, the journal concerned, the debit and credit
accounts, a label, and an amount, in a format an accounting firm
working with the SYSCOHADA chart of accounts can use directly.

::: info
Only expenses already approved by an administrator appear in this
export; an expense still pending does not show up here.
:::

## Export by class

Click **Export by class** to download a statement that details, for
every student in every class, the status of each fee item (amount due,
amount paid, remaining balance, percent paid) along with their list of
payments. This is the best format for a class-by-class follow-up.
