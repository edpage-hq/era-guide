# Registre et emploi du temps

Cette page couvre deux consultations indépendantes : le registre de votre
classe si vous êtes professeur principal, et votre propre emploi du temps,
accessible à tout enseignant.

## Le registre de classe (professeur principal)

Si vous êtes désigné professeur principal d'une ou plusieurs classes, le
menu **Notes → Ma classe** vous donne une vue consolidée de chacune d'elles.

Pour chaque classe, un tableau récapitule, par élève :

| Colonne                  | Contenu                                         |
| ------------------------ | ----------------------------------------------- |
| Élève                    | Nom de l'élève                                  |
| Moyenne annuelle         | Moyenne de l'élève sur l'année, toutes matières |
| Absences non justifiées  | Nombre d'absences sans justificatif approuvé    |
| Incidents disciplinaires | Nombre d'incidents enregistrés pour cet élève   |

Ce tableau est une vue de suivi en lecture seule. À côté du nom de chaque
classe, le bouton **Appréciations de fin de période** vous amène à la
saisie décrite dans
[Bulletins et cahier de textes](/guide/enseignant/bulletins-et-cahier-texte).

Si vous n'êtes actuellement professeur principal d'aucune classe, la page
l'indique et ne propose rien d'autre.

## Consulter votre emploi du temps

Le menu **Emploi du temps → Mon emploi du temps** affiche vos créneaux de
cours de la semaine : jour, heure de début, heure de fin, classe et
matière. Le bouton **Exporter (iCal)** télécharge votre emploi du temps
dans un fichier que vous pouvez importer dans votre application de
calendrier personnelle (Google Agenda, Outlook, Apple Calendrier…).
