# Secrétariat

Le secrétariat est la porte d'entrée des candidatures : c'est vous qui
examinez les dossiers déposés par les familles — en ligne via le
formulaire public, ou saisis directement par la caisse pour une famille
présente sur site — et qui décidez de les valider ou de les refuser.
Vous gérez également les demandes de transfert d'un élève déjà inscrit
d'un site à un autre. Le menu de gauche vous donne accès à deux pages :

- **[Dossiers à traiter](/guide/secretariat/candidatures)** — la file
  d'attente des candidatures reçues, avec les documents joints et la
  décision d'affectation à une classe.
- **[Mobilité inter-site](/guide/secretariat/transferts-sites)** — les
  demandes de transfert d'un élève entre deux sites de l'établissement.

Une fois qu'un dossier est validé, l'élève est inscrit dans une classe et
son dossier financier apparaît chez la caisse, qui prend le relais pour
les frais et les paiements — voir le
[guide de la caisse](/guide/caissier/).
