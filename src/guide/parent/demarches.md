# Démarches

Cette page explique deux démarches que vous pouvez effectuer vous-même
pour un enfant, sans passer par le secrétariat : justifier une absence et
demander un transfert de site.

## Justifier une absence

Quand votre enfant a été marqué absent ou en retard, vous pouvez envoyer
une justification directement depuis sa fiche :

1. Sur la fiche de l'enfant, allez dans la section **Présences**.
2. Repérez la ligne correspondant au jour concerné (statut **Absent** ou
   **Retard**) et cliquez sur **Justifier**.
3. Dans la fenêtre **Justifier cette absence**, saisissez le **Motif**.
4. Si vous avez un document à l'appui (certificat médical, etc.), ajoutez-le
   dans **Pièce justificative** — formats acceptés : PDF, JPG ou PNG. Ce
   champ est optionnel.
5. Cliquez sur **Envoyer**.

Votre justification apparaît alors avec le statut **En attente d'examen**.
L'établissement l'examine et la fait passer à **Justifiée** ou
**Rejetée** ; le statut se met à jour directement sur la fiche de votre
enfant.

## Demander un transfert de site

Si vous souhaitez inscrire votre enfant sur un autre site de
l'établissement (un autre campus, par exemple), vous pouvez soumettre une
demande de transfert :

1. Sur la fiche de l'enfant, allez dans la section **Mobilité inter-site**.
2. Cliquez sur **Demander un transfert** — ce bouton n'est disponible que
   si aucune demande n'est déjà en attente pour cet enfant.
3. Dans la fenêtre **Demander un transfert inter-site**, choisissez le
   **Site de destination** et le **Département de destination** souhaités.
4. Ajoutez un **Motif** si vous le souhaitez (facultatif).
5. Cliquez sur **Envoyer la demande**.

La demande apparaît dans le tableau en dessous avec la date, le site
d'origine, le site de destination et son statut : **En attente**,
**Approuvé** ou **Refusé**. Tant qu'une demande est en attente, vous ne
pouvez pas en soumettre une nouvelle pour le même enfant.
