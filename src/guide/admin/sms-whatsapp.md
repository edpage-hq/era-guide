# SMS et WhatsApp

Les notifications aux familles arrivent dans l'application et par e-mail.
Avec cette option, certaines peuvent aussi partir **par SMS ou sur
WhatsApp**, sur le téléphone des parents qui ont donné leur numéro. C'est
utile pour les familles qui consultent peu leurs e-mails.

La page s'ouvre par **Administration → SMS et WhatsApp**. Elle n'est
visible que par les administrateurs, et seulement si votre licence
comprend le pôle **Relations familles**.

## Un opérateur, des crédits

Les messages passent par un opérateur SMS ou WhatsApp. Chaque message
consomme un crédit acheté auprès de cet opérateur. Les crédits ne sont pas
compris dans la licence ERA : ils s'achètent séparément, sur devis.
Contactez edPage pour activer l'option.

Tant qu'aucun opérateur n'est raccordé, la page affiche **Pas
d'opérateur** : les familles restent prévenues dans l'application et par
e-mail, comme d'habitude.

::: info Établissements hébergés sur Era Admission
L'option n'est pas encore proposée aux établissements hébergés sur la
plateforme partagée. Elle concerne pour l'instant les installations
propres à un établissement.
:::

### Le mode pilote

Avant le choix définitif de l'opérateur, edPage peut activer un **mode
pilote**. Aucun message ne part réellement : chacun est écrit dans le
journal de l'application. Tout le reste fonctionne comme avec un
opérateur (qui reçoit quoi, le décompte du mois). C'est l'occasion de
choisir les notifications à envoyer et de vérifier que les parents ont
renseigné leur numéro.

## Choisir ce qui part par téléphone

1. Si l'opérateur propose les deux, choisissez **Envoyer par** : SMS ou
   WhatsApp.
2. Sous **Notifications envoyées**, cochez celles qui partent aussi sur le
   téléphone : absence non justifiée, bulletin publié, paiement
   enregistré, etc. Seules les notifications destinées aux familles sont
   proposées : celles du personnel ne partent jamais par SMS.
3. Cliquez sur **Enregistrer**.

Par défaut, aucune n'est cochée. Chaque message coûtant un crédit,
gardez celles qui comptent vraiment pour les familles.

Le message reprend le titre et le texte de la notification, dans la
langue choisie par le parent. Un SMS est limité à 306 caractères, un
message WhatsApp à 1 000 : au-delà, il est coupé.

## Qui reçoit les messages

Un parent reçoit une notification par téléphone si les trois conditions
sont réunies :

- l'établissement envoie ce type de notification (case cochée ci-dessus) ;
- le parent a un **numéro de téléphone** sur son compte ;
- il n'a pas désactivé l'envoi par téléphone pour ce type, dans ses
  préférences.

Le numéro vient de deux endroits :

- **le dossier de candidature** : à l'approbation d'une admission, le
  numéro du tuteur est reporté sur son compte parent, s'il n'en avait pas
  déjà un ;
- **le parent lui-même**, dans **Paramètres → Profil** (voir
  [Prise en main](/guide/prise-en-main#parametres-du-compte)).

Un administrateur peut aussi le saisir ou le corriger depuis la fiche de
l'utilisateur, dans
[Personnel et comptes utilisateurs](/guide/admin/personnel-utilisateurs).
Les numéros s'écrivent avec l'indicatif du pays (par exemple
`+228 90 11 22 33`). Sans indicatif, celui du Togo (+228) est ajouté.

## Suivre les envois

Le bas de la page indique combien de messages sont partis ce mois-ci, et
combien l'opérateur en a refusé (crédit épuisé, numéro invalide...). Les
20 derniers envois sont listés avec la date, le destinataire, son numéro,
la notification et le statut **Envoyé** ou **Refusé**. Survolez un statut
**Refusé** pour voir la raison donnée par l'opérateur.

Un message refusé n'est pas renvoyé. La notification, elle, est bien
arrivée dans l'application et, selon les préférences du parent, par
e-mail.

Ce journal est effacé après 13 mois.
