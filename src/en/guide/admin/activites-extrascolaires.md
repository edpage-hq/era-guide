# Extracurricular activities

This section covers setting up the extracurricular activity catalog
(swimming, drama, etc.) and scheduling its sessions. Tracking attendance
at these sessions is then the student-life role's job, not
administration's.

## Create an activity

**School setup → Extracurricular Activities** lists the
school's activity catalog.

To create an activity:

1. Click **New activity**.
2. Fill in the **Name** and, optionally, a **Description**.
3. Click **Save**.

## Schedule a session

**School setup → Extracurricular Sessions** schedules
recurring slots for an activity, by site and level, with a designated
supervisor.

To create a session:

1. Click **New session**.
2. Fill in the "Activity" section fields below.
3. Fill in the "Schedule" section fields below.
4. Click **Save**.

"Activity" section:

| Field      | Detail                                   |
| ---------- | ---------------------------------------- |
| Activity   | chosen from the catalog                  |
| Site       | —                                        |
| Department | the level this session is for            |
| Supervisor | staff member responsible for the session |

"Schedule" section:

| Field       | Detail |
| ----------- | ------ |
| Day of week | —      |
| Start time  | —      |
| End time    | —      |

Each session can then be edited or deleted individually from the session
list.
