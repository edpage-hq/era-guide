# Leave requests

Leave is one of the few parts of ERA that doesn't depend on your role:
**every staff member** files their own requests, whether they teach, run
the cash desk, the infirmary or the boarding house. Only the decision is
reserved for the school's administration.

## Filing a request

From **My leave requests**:

1. Pick the **type**: paid leave, unpaid leave or sick leave.
2. Set the **start date** and **end date**.
3. Write the **reason**.
4. Click **Submit request**.

The request is created as **Pending**. There's nothing else to do: it
appears in the administration's own queue.

## Following your requests

The **History** section of the same page lists your past and current
requests with their status:

| Status   | What it means                                            |
| -------- | -------------------------------------------------------- |
| Pending  | Filed, not reviewed yet                                  |
| Approved | Granted by the administration                            |
| Rejected | Refused — the rejection reason is shown with the request |

You only ever see your own requests, never a colleague's.

::: tip Filing isn't open to everyone
This page assumes you have a staff record at the school. An account without
one (a parent, a student) has no access to it — see
[Staff and user accounts](/en/guide/admin/personnel-utilisateurs) for how
records are created.
:::

## Deciding on requests (administration)

An administrator gets an extra view, **Leave requests**, listing requests
from **all** staff.

For each request:

- **Approve** grants it immediately.
- **Reject** opens a confirmation dialog asking for a **rejection reason**.
  That reason is then visible to the person concerned in their own history
  — which is what saves them from having to come and ask why.

An already-decided request stays in the list with its outcome: the history
is a record, nothing is erased.
