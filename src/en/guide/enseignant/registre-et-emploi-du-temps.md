# Homeroom and schedule

This page covers two independent things: your homeroom class register if
you are a homeroom teacher, and your own schedule, available to every
teacher.

## The homeroom class register

If you are designated homeroom teacher for one or more classes, **Teaching →
My homeroom class** gives you a consolidated view of each of them.

For each class, a table summarizes, per student:

| Column               | Content                                                 |
| -------------------- | ------------------------------------------------------- |
| Student              | Student's name                                          |
| Annual average       | The student's average for the year, across all subjects |
| Unjustified absences | Number of absences with no approved justification       |
| Discipline incidents | Number of incidents recorded for this student           |

This table is a read-only tracking view. Next to each class's name, the
**End-of-period appreciations** button takes you to the entry screen
described in
[Report cards and lesson log](/en/guide/enseignant/bulletins-et-cahier-texte).

If you are not currently the homeroom teacher of any class, the page says
so and offers nothing else.

## View your schedule

**Teaching → My schedule** shows your class sessions for the week: day,
start time, end time, class and subject. The **Export (iCal)** button
downloads your schedule as a file you can import into your personal
calendar app (Google Calendar, Outlook, Apple Calendar…).
