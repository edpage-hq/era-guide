# Enseignant

En tant qu'enseignant, vous ne voyez que vos propres classes et matières :
celles pour lesquelles l'administrateur vous a explicitement affecté (côté
administration, menu **Paramétrage scolaire → Affectations enseignants**). Si une classe ou
une matière n'apparaît pas dans vos listes déroulantes, c'est qu'aucune
affectation ne vous relie encore à elle — signalez-le à l'administrateur.

Si vous êtes désigné **professeur principal** d'une classe, vous disposez en
plus d'une vue consolidée de cette classe et des appréciations générales de
fin de période, décrites dans la troisième page ci-dessous.

Ce guide couvre trois activités :

| Page                                                                         | Ce que vous y faites                                                                         |
| ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| [Notes et évaluations](/guide/enseignant/notes-et-evaluations)               | Créer une évaluation, saisir les notes, renseigner les observations de compétences           |
| [Bulletins et cahier de textes](/guide/enseignant/bulletins-et-cahier-texte) | Rédiger les appréciations de bulletin, tenir le cahier de textes                             |
| [Registre et emploi du temps](/guide/enseignant/registre-et-emploi-du-temps) | Consulter le registre de votre classe (professeur principal) et votre propre emploi du temps |

Pour tout ce qui concerne votre compte personnel (connexion, profil,
sécurité, notifications), commun à tous les rôles, voir
[Bien démarrer](/guide/prise-en-main).
