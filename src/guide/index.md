# Quel est votre rôle ?

Chaque rôle a son propre guide, centré sur ce qu'il peut réellement faire
dans ERA. Si vous découvrez l'app, commencez par [Bien démarrer](/guide/prise-en-main)
(connexion, profil, sécurité, notifications) — commun à tous les rôles.

| Rôle                                 | Ce qu'il permet de faire                                                                                     |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| [Administrateur](/guide/admin/)      | Configurer l'établissement, gérer le personnel, les élèves, les frais, les emplois du temps et les bulletins |
| [Secrétariat](/guide/secretariat/)   | Traiter les candidatures et les demandes de transfert de site                                                |
| [Caisse](/guide/caissier/)           | Inscrire un élève, encaisser les paiements, gérer les dépenses et l'export comptable                         |
| [Enseignant](/guide/enseignant/)     | Saisir les notes, rédiger les appréciations, tenir le cahier de textes et le registre de classe              |
| [Vie scolaire](/guide/vie-scolaire/) | Suivre les présences, la discipline, la cantine, le transport et les activités extrascolaires                |
| [Internat](/guide/internat/)         | Gérer les lits et les présences en internat                                                                  |
| [Infirmerie](/guide/infirmerie/)     | Enregistrer et suivre les visites médicales des élèves                                                       |
| [Parent](/guide/parent/)             | Suivre ses enfants, télécharger leurs documents, payer en ligne et faire ses démarches                       |
| [Élève](/guide/eleve/)               | Consulter son propre espace, ses documents et son emploi du temps                                            |

Les **[demandes de congé](/guide/conges)** sont l'exception : tout membre
du personnel dépose les siennes, quel que soit son rôle.

Vous cherchez plutôt l'inscription en ligne d'un établissement ou le
panneau interne edPage ? C'est du côté d'[Era Admission](/admission/).
